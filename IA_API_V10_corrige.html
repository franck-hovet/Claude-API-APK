Historique commun (synchronisation)

L’historique est copié dans un Gist GitHub privé. Pour le créer, utilise un jeton personnel classique avec uniquement le droit « gist » : Créer un jeton GitHub avec le droit gist. Colle-le ici. Laisse l’ID vide sur le premier appareil ; il sera retrouvé ou créé automatiquement. Sur les autres appareils, utilise un jeton du même compte GitHub, avec le droit gist, et le même ID. Si tu synchronises aussi les clés API chiffrées, le jeton doit être strictement identique sur les appareils : il sert aussi de clé de chiffrement.

À savoir : le Gist est privé et appartient au compte GitHub utilisé. Un jeton appartenant à un autre utilisateur ne lui donne pas accès à ce Gist. Le partage entre personnes ayant des comptes GitHub différents n’est donc pas assuré par cette synchronisation ; utilise le bouton « Partager » d’une discussion pour un partage ponctuel.

Transférer la configuration GitHub : crée un fichier chiffré par mot de passe, envoie ce fichier sur l’autre appareil, puis importe-le là-bas. Le jeton n’est jamais écrit en clair dans ce fichier. Transmets le mot de passe séparément. Les clés API des fournisseurs ne sont pas incluses.
